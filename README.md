## Featured project

### [Relay](https://github.com/brendanmair-project/relay-payments): payments reliability, end to end

A merchant payments platform on synthetic data. Each payment gets one timeline, each failure gets a plain-language explanation, and Relay fails over between two simulated processors. In a scripted outage, failover raised payment success from **58% to 89%**. It includes signed webhooks, a Python SDK, an operator console and a pre-registered adaptive-routing experiment reported honestly, results and all.

`Python` `FastAPI` `PostgreSQL` `Valkey` `Next.js` `Docker Compose`
